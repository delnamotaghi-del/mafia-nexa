# Mafia Nexa Android

برای ساخت APK بازی مافیا نکسا:

1. فایل `mafia-nexa-android-project.zip` را در ریشه همین مخزن آپلود کنید.
2. از تب **Actions**، گردش‌کار **Build Mafia Nexa APK** را باز کنید.
3. روی **Run workflow** بزنید.
4. پس از پایان موفق، از بخش **Artifacts** فایل `mafia-nexa-debug-apk` را دانلود و APK را روی گوشی نصب کنید.

فایل ZIP باید پوشه `mafia-nexa-android` را درون خود داشته باشد و شامل پروژه Android با فایل `app/build.gradle` باشد.
